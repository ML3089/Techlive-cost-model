# TechLive coordination – cost-benefit model

Python cost model supporting the DT504 Part A investment proposal, *TechLive Coordination Investment Proposal* (Data Informed Solutions, DT504).

## What's in this repository

| File | Purpose |
| --- | --- |
| `techlive_cost_model.ipynb` | The notebook: assumptions, cost model, cost-benefit table, chart, weighted scoring, scenarios and sensitivity checks |
| `chart.png` | The cumulative net saving chart produced by the notebook |

## How to run it

1. Open `techlive_cost_model.ipynb` in Jupyter, VS Code or Google Colab.
2. Run all cells. It needs only `pandas` and `matplotlib`.
3. To test different assumptions, change the values in Section 1 and run all cells again.

## About the data

All inputs are organiser estimates based on three TechLive events (hosted from Houston, Pune and the UK) and are not recorded data. No personal or confidential bp data is included. External pricing and benchmark figures are referenced in the proposal.
